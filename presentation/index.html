Зачем микрофронтенды?

  • Независимость команд — каждый модуль разрабатывается и деплоится отдельно
  • Масштабирование разработки — несколько команд, одно приложение
  • Инкрементальное обновление — обновляется только изменённый модуль
  • Технологическая гибкость — разные фреймворки в разных модулях

Но: накладные расходы на интеграцию, дублирование кода, рост размера поставки

5.4 CDP Tracing: GC + JS Parse/Compile — 5 релевантных метрик

// Tracing собирает V8 события во время загрузки страницы
const gcEvents: { dur: number }[] = [];
const compileEvents: { name: string; dur: number }[] = [];

client.on('Tracing.dataCollected', (data) => {
  for (const event of data.value || []) {
    // GC события
    if (event.cat?.includes('v8.gc') || event.name?.includes('GC')) {
      gcEvents.push({ dur: event.dur ? event.dur / 1000 : 0 }); // μs → ms
    }
    // Parse и Compile события
    if (event.cat?.includes('v8') &&
        ['V8.Compile','V8.CompileCode','V8.Parse','V8.ParseFunction']
          .includes(event.name)) {
      compileEvents.push({ name: event.name, dur: event.dur ? event.dur / 1000 : 0 });
    }
  }
});

await client.send('Tracing.end');

const gcCount          = gcEvents.length;
const gcTotalDurationMs = Math.round(gcEvents.reduce((s, e) => s + e.dur, 0));
const gcMaxDurationMs   = Math.round(Math.max(...gcEvents.map(e => e.dur)));

const parseEvents   = compileEvents.filter(e => e.name.includes('Parse'));
const compileOnly   = compileEvents.filter(e => e.name.includes('Compile'));
const jsParseMs     = Math.round(parseEvents.reduce((s, e) => s + e.dur, 0));
const jsCompileMs   = Math.round(compileOnly.reduce((s, e) => s + e.dur, 0));

7. Bundle Analysis — 7 из 10 релевантных

Node.js fs zlib

import { readdirSync, readFileSync, statSync } from 'fs';
import { gzipSync } from 'zlib';
import { join, extname } from 'path';

// Рекурсивный обход директории сборки
function getAllFiles(dir: string): string[] {
  const entries = readdirSync(dir, { withFileTypes: true });
  return entries.flatMap(e =>
    e.isDirectory() ? getAllFiles(join(dir, e.name)) : [join(dir, e.name)]
  );
}

// Анализ каждого файла
function analyzeBundleDir(dir: string) {
  const files = getAllFiles(dir);
  let totalSize = 0, totalGzip = 0;

  const byType: Record<string, { count: number; size: number }> = {};

  for (const file of files) {
    const size = statSync(file).size;
    const content = readFileSync(file);
    const gzip = gzipSync(content).length;
    const type = getFileType(extname(file)); // 'js' | 'css' | 'images' | ...

    totalSize += size;
    totalGzip += gzip;
    byType[type] = byType[type] || { count: 0, size: 0 };
    byType[type].count++;
    byType[type].size += size;
  }

  return { totalSize, totalGzip, fileCount: files.length, byType };
}

// Для MFE: вычисляем Runtime Size с учётом shared deps
// Module Federation загружает Vue, Pinia один раз (shared)
// Но каждый MFE содержит их в своём бандле на диске

function calculateRuntimeSize(mfeMetrics: MfeMetrics[]) {
  const sharedDeps = ['vue', 'pinia', 'vue-router'];
  let duplicatedSize = 0;

  // Находим дубликаты: shared dep встречается > 1 раза
  for (const dep of sharedDeps) {
    const occurrences = mfeMetrics.filter(m =>
      m.chunks.some(c => c.name.includes(dep))
    );
    if (occurrences.length > 1) {
      // Все кроме первого — дубликаты
      const sizes = occurrences.slice(1).map(m =>
        m.chunks.find(c => c.name.includes(dep))!.gzip);
      duplicatedSize += sizes.reduce((a, b) => a + b, 0);
    }
  }

  return totalMfeGzip - duplicatedSize; // приближение к реальной загрузке
}

Выводы

  1. Быстрый старт оболочки — MFE выигрывает по DOMContentLoaded (+61%) и Load (+65%) за счёт маленького entry shell (18.6 vs 59 KB)

  2. Проигрыш по Lighthouse — ухудшение SI, FCP, LCP, TTI, TBT и итогового Performance Score (-19.5%) из-за отложенной загрузки модулей

  3. Корень проблемы — JS обработка — даже при загрузке 3 из 6 MFE: JS Parse ×2.3, JS Compile ×2.7, Task Duration ×1.95 (35 скриптов с 5 доменов)

  4. E2E сопоставимо — функциональная скорость практически одинакова, разница в пределах погрешности

  5. Bundle — entry shell в 3.2 раза легче, но суммарно MFE в 2.6 раза тяжелее (runtime +60.5%)

Итог


Микрофронтенды дают организационные преимущества
и быстрый старт,

но приносят измеримые затраты производительности
на уровне обработки JavaScript в браузере.


Решение о применении MFE должно учитывать
